iLovePDF Webapp using Streamlit

Overview

We are building an iLovePDF-inspired web application using Streamlit in Python. This web app aims to provide various PDF manipulation functionalities, such as merging, splitting, and more.

Current Features

Merge PDFs: Users can upload multiple PDFs, reorder them, and merge them into a single file.
